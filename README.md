# Dashboard Masterplan Kawasan Cagar Budaya Gajah Mada

Dashboard interaktif yang merangkum **Peraturan Walikota Denpasar Nomor 44 Tahun 2025** tentang Masterplan Kawasan Heritage Gajah Mada (2025–2045): status perencanaan, zonasi, desain per ruas jalan beserta gambarnya, dan rencana anggaran biaya.

## Isi repositori

- `index.html` : halaman dashboard (HTML, CSS, dan JavaScript dalam satu berkas)
- `images/` : 57 gambar desain dan peta zonasi (Gambar 6.1–6.57 pada lampiran dokumen)
- `.nojekyll` : agar GitHub Pages menyajikan berkas apa adanya

## Cara menampilkan di GitHub (GitHub Pages)

1. Buat repositori baru di GitHub, lalu unggah seluruh isi folder ini (termasuk folder `images`).
2. Buka **Settings → Pages**.
3. Pada **Build and deployment**, pilih **Source: Deploy from a branch**, branch **main**, folder **/ (root)**, lalu **Save**.
4. Tunggu sekitar 1–2 menit. Dashboard tersedia di `https://<username>.github.io/<nama-repositori>/`.

Membuka `index.html` langsung di halaman repositori GitHub hanya menampilkan kode, bukan tampilannya. Untuk melihat tampilannya, gunakan GitHub Pages atau buka `index.html` di peramban setelah folder diunduh.

## Sumber dan catatan

- Sumber: Perwali Kota Denpasar No. 44 Tahun 2025 beserta lampiran Laporan Akhir (PT Tata Rancana Hijau).
- Dashboard ini merangkum dokumen tersebut dan bukan pengganti teks resminya.
- Angka biaya per ruas jalan dihitung ulang dari Tabel 6.1 dokumen. Angka tersebut perkiraan perencanaan, bukan realisasi.
- Dokumen tidak memuat laporan progres konstruksi.
- Hak cipta gambar ada pada penyusun dokumen aslinya. Periksa ketentuan penggunaan sebelum menyebarluaskan.
